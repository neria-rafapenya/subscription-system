# Orden de implementación aprobado

1. Completar y probar el flujo local de desarrollo.
2. Cerrar el modelo de servicios, planes y estados de suscripción desde el backoffice.
3. Añadir autenticación Cognito en integración.
4. Añadir DynamoDB, S3, Secrets Manager, Lambda y API Gateway en integración.
5. Probar PayPal Sandbox y webhooks en integración.
6. Preparar presupuesto AWS y límites de gasto.
7. Construir el área web de administración protegida.
8. Duplicar el despliegue para producción con secretos y datos independientes.

Desarrollo no ejecuta Terraform y no debe necesitar una cuenta AWS para trabajar.
