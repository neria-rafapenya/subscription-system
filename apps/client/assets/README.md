# Iconos de WAD Gestoría

Conjunto vectorial de marca para móvil y web:

- `logo-mark.svg`: marca cuadrada para cabeceras y botones.
- `logo-wordmark.svg`: logotipo horizontal para splash, documentación y web.
- `favicon.svg`: favicon cuadrado simplificado.
- `icon.svg`: icono principal cuadrado para Expo.
- `adaptive-icon-foreground.svg`: primer plano transparente para el icono adaptativo de Android.
- `icon.png`, `favicon.png` y `adaptive-icon-foreground.png`: copias PNG listas para Expo y las tiendas.

La marca se mantiene en SVG para que pueda reutilizarse sin pérdida de calidad. Las configuraciones de Expo apuntan a estos recursos vectoriales; si una tienda exige rasterización, se exportan a PNG durante el proceso de compilación.
